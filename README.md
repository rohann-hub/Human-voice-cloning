## 📖 Overview

**Human Voice Cloning** is an AI-powered voice cloning project that generates natural, expressive, and high-quality speech from a short reference audio sample.

Simply provide a clean voice recording and the text you want to synthesize, and the model generates speech while preserving the speaker's vocal characteristics.

---

## ✨ Features

- 🎤 Human voice cloning from a reference audio
- 🗣️ Natural and expressive speech synthesis
- ⚡ Fast inference
- 🎯 High-quality voice preservation
- 📒 Google Colab ready
- 🔥 Easy to use with minimal setup

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/rohann-hub/Human-voice-cloning.git

cd Human-voice-cloning
```

### Open in Google Colab

Upload or open the notebook in Google Colab and run all cells sequentially.

---

## 🎯 Usage

1. Upload a clean reference audio.
2. Enter the text to synthesize.
3. Run the notebook.
4. Download the generated speech.
